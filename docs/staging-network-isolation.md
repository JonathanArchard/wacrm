# Staging external network review

The server-side explicit transport wrapper defaults to deny outside opted-in production. In restricted mode only the exact staging application origin and Supabase REST/Auth/Storage/Realtime HTTPS paths are permitted; redirects are rejected. Meta, AI, webhooks, automation HTTP actions, the shared server SDK, middleware and identified service-role clients use this boundary. Preserve existing per-service controls and SSRF checks. Production opt-in preserves existing transport behavior.

Residual risks: browser SDK, browser media blob fetching and navigation, external images and fonts, Realtime WebSocket connections, SDK internals, direct global fetch or DNS, edge functions, hosted database network extensions, MCP separate process, and other uninspected paths are not covered by this wrapper. Existing SSRF DNS resolution checks do not pin IPs and do not prevent DNS rebinding. No infrastructure firewall is claimed. Before deployment, inventory all remaining network calls with local source search, verify browser destination restrictions and provider settings, audit dependency lockfiles and enforce a suitable runtime-specific egress control. No live network tests, deployment, or provider configuration changes performed. Production promotion requires EXTERNAL_NETWORK_ENABLED=true.
